# suntech-legal

Pages publiques (politique de confidentialité et conditions d'utilisation) pour l'application interne **SunTech AutoQuote**, hébergées ici afin de fournir des URL publiques lors de la demande d'accès à l'API QuickBooks Online (Intuit Developer).

Le code source de l'application reste dans le dépôt privé `Autoquotes`.

## Contenu

- [`index.html`](index.html) — page d'accueil
- [`confidentialite.html`](confidentialite.html) — politique de confidentialité
- [`conditions-utilisation.html`](conditions-utilisation.html) — conditions d'utilisation (CLUF)

## Publication

Servi via GitHub Pages (branche `main`, racine `/`).
